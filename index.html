1. Simple Interest: Calculating Interest Earned

Interest is calculated strictly on the original principal ($P$) for each time period[cite: 1].

$$I = P \times r \times t$$

2. Simple Interest: Calculating Total Future Value

$$FV = P \times (1 + r \times t) \quad \implies \quad P = \frac{FV}{1 + r \times t}$$

3. Compound Interest: Future Value

Interest earned is reinvested to generate additional interest in subsequent periods[cite: 1].

$$FV = PV \times (1 + r)^n$$

$$FV = PV \times e^{r \times t}, \quad PV = FV \times e^{-r \times t}$$

1. Present Value of an Ordinary Annuity

$$PV = PMT \times \left[\frac{1 - (1 + r)^{-n}}{r}\right]$$

$$FV = PMT \times \left[\frac{(1 + r)^n - 1}{r}\right]$$

3. Multiple Irregular Cash Flows & Net Present Value (NPV)

$$PV = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t}, \quad NPV = CF_0 + \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t}$$
